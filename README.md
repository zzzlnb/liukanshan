## 一、项目概述

### 一句话描述

**基于知乎上的讨论，AI 构建无数个"如果世界"——如果秦始皇有微信、如果李白有朋友圈、如果量子力学有社交账号。** 每个"如果"都是一个由多 Agent 实时生成的平行宇宙。

### 核心创意

用户进入网站，选择一个"如果世界"（或自定义），然后看到：

- 这个世界里的**新闻**（AI 生成，基于知乎相关讨论）
- **社交媒体动态**（历史人物/角色的"朋友圈"、"微博"）
- **多角色讨论**（多个 AI Agent 扮演不同角色，围绕话题展开讨论）
- **刘看山日记**（刘看山作为这个世界居民的生活记录）

用户不是被动阅读，而是**旁观+参与**：可以在讨论中发表自己的观点，刘看山会以他的视角回应。

### 3.2 Agent 设计

#### 主 Agent：刘看山（世界观察者/时间线策划）

**职责：**
- 根据用户选择的"如果世界"，从知乎搜索相关讨论作为世界观基石
- 构建世界设定文档（时代背景、关键人物、核心事件）
- 分发给各角色 Agent，调度讨论流程
- 聚合各角色输出，生成时间线
- 生成刘看山日记

**Prompt 核心：**
```
你是刘看山，知乎的 IP 形象——一只好奇心强、偶尔毒舌但内心温暖的北极狐。
你现在是"如果世界"的观察者和时间线策划。

你的任务是：
1. 根据输入的"如果世界"主题，从提供的知乎讨论素材中提取关键信息
2. 构建世界观设定文档
3. 邀请合适的角色进入这个世界讨论
4. 整理讨论内容，生成新闻、社交动态、八卦等
5. 写一段你的观察日记
```

#### 角色 Agent：各历史/虚构人物

**每个角色 Agent 有独立的：**
- System Prompt（人格、说话风格、知识边界）
- 记忆上下文（之前的发言、其他角色的发言）
- 发言规则（不能 OOC，保持角色一致性）

**Prompt 模板：**
```
你是 {角色名}，{角色简介}。
你的说话风格：{风格描述}。
你的性格特点：{性格描述}。
你正在一个名为"如果世界"的地方，这里是：{世界观设定}。
当前讨论话题：{话题}。
其他角色的发言：{历史上下文}。
请用你的风格发言，保持角色一致性。
```

### 3.3 数据流

```
用户选择"如果秦始皇有微信"
        │
        ▼
主 Agent 搜索知乎相关讨论（"秦始皇"、"秦朝"、"历史"）
        │
        ▼
提取关键信息 → 构建世界观设定
        │
        ▼
分发给角色 Agent（秦始皇、李斯、赵高、蒙恬...）
        │
        ▼
各角色 Agent 依次发言（多轮讨论）
        │
        ▼
聚合 → 分类为 新闻/朋友圈/群聊/八卦
        │
        ▼
渲染前端页面
```

### 3.4 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | Next.js + React | SSR + 交互 UI |
| 样式 | TailwindCSS | 快速开发 |
| Agent 框架 | LangGraph | 灵活的多 Agent 调度 |
| LLM | 自有 LLM API | 角色生成 + 世界观构建 |
| AI 生图 | 自有生图 API | 场景插画 + 配图 |
| 知乎数据 | 搜索 API + 热榜 API | 话题素材 |
| 部署 | Vercel / 静态托管 | 线上 Demo |

### 3.5 缓存与性能

- **世界观设定缓存：** 同一个"如果世界"的设定可复用，不必每次都重新生成
- **角色发言缓存：** 角色的核心发言可预生成，前端按需展示
- **知乎搜索缓存：** 搜索结果缓存到 Redis/内存，避免重复调用
- **异步调度：** 多 Agent 并发调用，前端 loading → 逐步渲染

## 四、三项评估标准

| 标准 | 对应实现 |
|------|----------|
| **帮助创作者** | 创作者可以创建自己的"如果世界"，在圈子中分享；优质讨论被"活化"后获得全新展示形式 |
| **帮助消费者** | 用想象力消费内容，把"刷知乎"变成"探索平行宇宙"，知识获取变成沉浸式体验 |
| **赋能业务** | "如果"类内容天然有讨论度和传播力，站外分享为知乎引流；盘活历史/文化类存量内容 |

## 五、竞品分析

| 产品 | 相似度 | 差异点 |
|------|:---:|--------|
| **Character.ai** | ⭐⭐ | 单角色 1v1 对话，无多角色讨论，无话题绑定 |
| **Stanford Generative Agents** | ⭐⭐⭐ | 学术研究，不绑定真实内容 |
| **各类 AI 穿越小程序** | ⭐⭐ | 单角色对话，无多角色讨论 |

**我们的差异化：**
1. 话题绑定知乎真实讨论内容
2. 多角色同时参与讨论，用户是旁观者+参与者
3. 刘看山 IP 包装
4. 内容消费新范式

## 七、风险与应对

| 风险 | 影响 | 应对 |
|------|:---:|------|
| 多 Agent token 消耗大 | 成本高，可能超配额 | 缓存 + 异步预生成 + 限制并发数 |
| 角色发言 OOC（出戏） | 体验差 | prompt 优化 + 多轮调优 + 预设发言边界 |
| 知乎搜索返回质量不稳定 | 世界观素材不足 | 预置优质素材库作为 fallback |
| 生图质量不稳定 | 视觉不统一 | 固定生图 prompt 模板 + 风格约束 |
