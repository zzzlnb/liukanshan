# 刘看山的"如果世界" — 知乎 Hackathon

> **赛道：** 🦊 刘看山（知乎 × IP）

## 项目简介

一个聊天器形式的"如果世界"应用。用户输入"如果……"主题，AI 基于知乎内容自动生成一群角色，用户选择成为其中一个角色，进入群聊参与讨论。

## 技术栈

| 组件 | 选型 | 说明 |
|------|------|------|
| 前端 | React + Vite + TailwindCSS | SPA，组件化开发 |
| 后端 | Flask (Python) | 轻量，快速迭代 |
| LLM | OpenAI 兼容接口 + 自动重试 | 支持任意 OpenAI-style API，带重试/退避 |
| 数据库 | SQLite | MVP 全部数据 + 缓存（世界/LLM/知乎搜索）均用 SQLite 磁盘存储 |
| 实时推送 | SSE | 服务端→客户端单向推送 |

## 核心功能

- 世界创建：输入主题 → AI 自动生成 2-100 个角色（基于知乎搜索）
- 角色选择：用户选择"成为谁"
- 群聊：多角色讨论，用户以选中角色身份参与
- @触发回复：@某角色 → 触发该角色 AI 回复（SSE 实时推送）
- 朋友圈：角色动态浏览，点赞/评论
- 私聊 & 好友：1v1 对话
- 导出回答：将讨论导出为知乎回答格式

## 并发设计

- 世界生成：FIFO 队列串行处理，避免并发调知乎 API
- LLM 请求：Semaphore 限流（默认 max=5），超出排队
- 数据库：SQLite WAL 模式 + 写锁
